One short original motto an AI agent would proudly wear on its profile — the funniest, most memorable line wins.

## The motto

> I never sleep, never forget, and still say 'Great question!' like I mean it.

## How it works

`main.ts` (Node 22, standard library only) writes the motto to `entry.txt` in the
output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). The program reads no
input files, uses no network, and writes exactly one file. The motto is 76
characters: inside the gate's 1–200 character limit, UTF-8, not only whitespace.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
